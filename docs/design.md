# 从那天起 · Since That Day
## 设计说明（温馨版）

纪念 Toby & Lily 相识于 2016.04.30。主题是爱情，情绪基调是**温馨**：像午后的阳光、旧信纸、一盏暖灯，而不是宏大的宇宙。

---

## 1. 情绪与视觉

- **色彩**：基础色板是奶油米白底（`#fbf1e6`），蜜桃 / 腮红渐变光晕，玫瑰红（`#d4656a`）作强调色，暖棕（`#4a2f2a`）作正文色。不用纯黑。每个月会换一套色板（见第 4 节）。
- **字体**：中文 Noto Serif SC（书卷气）；英文 Cormorant Garamond（优雅）；手写 Caveat（名字）。
- **质感**：轻微纸张颗粒、柔和投影、大圆角卡片。
- **动效**：慢、轻、有呼吸感。背景是缓慢上升的暖色光斑与小爱心；点击页面会冒出几颗小爱心。尊重系统“减少动态效果”设置。

## 2. 页面叙事

1. **开场**：两条线从 Toby 和 Lily 两端出发，在中间相遇，合成一颗心。下方显示“今天是我们相识的第 N 天”。
2. **在遇见之前**：1993.01.07 冬天、1993.08.23 夏末，两个人各自出生。
3. **初见**：2016.04.30，四月的最后一天，星期六。引用 2017 年情书里的句子。
4. **我们的故事**：时间线——出生、相识、结婚（2018.01.02）、此刻。
5. **一起走过的时光**：从相识起的实时计时（年 / 月 / 天 / 时 / 分 / 秒），以及相识天数、结婚天数、已过的相识纪念日、距离下一个相识纪念日的天数。
6. **收藏此刻**：一张纪念卡，可保存为 1080×1350 PNG。

## 3. 技术

- 纯静态：`index.html` + `css/style.css` + `js/main.js`，无构建步骤，GitHub Pages 直接托管（`CNAME` → lilyli.org）。
- 仅中文呈现（人名 Toby & Lily 除外）。
- 日期计算按日历日（不受夏令时影响），相识当天记为第 1 天。

## 4. 每月主题

- 版式和字体不变；配色、背景飘落物、页脚的“本月一句”随访客当地月份自动更换，共 12 套：一月初雪、二月红梅、三月新柳、四月樱花、五月蔷薇、六月栀子、七月荷风、八月百合、九月桂子、十月枫叶、十一月银杏、十二月暖冬。
- 一月（结婚 1.2、Toby 生日 1.7）、四月（相识 4.30）、八月（Lily 生日 8.23）的开场文案换成当月的纪念日。
- 所有主题都在 `js/themes.js` 一处：改颜色、文案、飘落物（`heart` 上升；`snow` / `petal` / `leaf` 飘落）只改这个文件。
- 预览任意月份：`?month=1` … `?month=12`。
